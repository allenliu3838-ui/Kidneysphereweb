## 服务器执行

将交付的 `kidneysphere-specialties-20260919.pyz` 上传服务器，进入它所在目录：

```bash
python3 kidneysphere-specialties-20260919.pyz check
python3 kidneysphere-specialties-20260919.pyz apply
```

默认目录是 `/var/www/kidneysphere`。只修改 `index.html`，新增 `daily-literature.js` 与 `daily-literature.css`。不修改医生站、支付、账号、Nginx 或其他静态资源。无须安装依赖或重启服务。

检查成功返回 `READY`；应用成功返回 `APPLIED` 和实际备份目录；重复应用返回 `NO_CHANGE`。若页面已被其他更新改变则返回 `STOP`，应重新基于当前页面制作补丁，不应删除校验或强行覆盖。

回滚（替换为应用输出的真实目录）：

```bash
python3 kidneysphere-specialties-20260919.pyz rollback /root/kidneysphere-specialty-backups/实际备份目录
```

回滚仅恢复本次三个文件；会检查有无后续修改，防止覆盖新工作。数据库迁移不由本包重复执行。

- `migration.sql` 记录已应用的完整数据库变更，带原函数指纹保护。`latest-by-specialty.sql` 是新增接口定义。
