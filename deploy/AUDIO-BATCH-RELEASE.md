# 批量音视频课程上传

学习中心管理员表单下新增“批量上传视频 / 音频”。先填写上方公共频道、主讲人、内容来源、专科和访问权限，再一次选择多份文件。文件名会生成可编辑的课程标题，“第几章”按数字顺序排列，支持中文和阿拉伯数字。截图中的整套 MP3 可以一次选择；每个文件各保存一条课程。

默认保存草稿，也可选择上传后上架。点击开始时统一冻结本批设置；停止后继续沿用原设置，新加入的文件使用下一次开始时的设置。文件顺序上传，进度、错误和重试按文件显示。上传已完成而保存失败时，重试只保存课程，固定课程 UUID 防止响应丢失造成重复记录。重复选择检测限当前队列的文件名、大小和修改时间，不是跨会话内容查重。

请保持页面打开。当前队列和未完成文件不跨页面刷新恢复；已保存课程可在最近课程中查看。停止后保存请求会完成确认，已成功上传的待保存文件会保留。音频处理、付费权限和正式播放器沿用音频版本，见 [音视频说明](AUDIO-RELEASE.md)。

## 发布与恢复

批量更新包包含音频上传/播放器及批量界面的固定 13 个资源，可直接从蓝白主题版、深海蓝主题版或前一音频版升级。不需要先安装前一音频包。只读检查实际 API 进程、网页/后端路径和版本；未知修改不会覆盖。

上传交付的 `.pyz` 到服务器 `/root/`，校验 SHA-256 后运行 `python3 包文件.pyz --inspect`。依据该次检查输出的 `APPLY_COMMAND` 执行更新。实际文件自动备份；升级和恢复均有哈希校验。若已安装前一音频版、两份后端处理器完全相同，则不重启 API；旧主题版首次加入音频处理器时，仅重启已核实的 API 进程。

保存输出中的 `BACKUP` 和 `ROLLBACK_COMMAND`。如要恢复更早音频前版本，应先回滚批量包，再用原音频包恢复它自己的备份。网站首页、登录逻辑、数据库结构、课程权益和已有媒体不在修改范围内。其他站点及 Nginx 不重启。

## 核验范围

自动测试覆盖章节排序、整批设置冻结、单条/批量互斥、停止竞态、失败阶段重试、固定 UUID 幂等保存，以及上传 API 共享限流。预览使用模拟文件和上传/保存回调，不访问实际 VOD 或数据库。

上线后先用 2–3 份真实 MP3 验证上传与课程保存，再在阿里云确认音频处理结果；使用具备对应权限的账号检查站内收听，并回归一节原有付费视频。模拟测试不能代替真实账号和阿里云转码验证。
