# KidneySphere 首页精简与手机适配 · 2026-09-13

## 已批准的方向

用户确认以视频学习与培训报名为主，并明确保留“证据与合作生态”（核心专家、旗舰中心、共建单位、合作单位）。本次落实用户认可的浅白蓝效果图，合作目录沿用深蓝模块。手机友好是本轮重点。

## 范围与发布边界

- 修改当前独立改版分支 codex/portal-home-20260913，沿用草稿 PR #186 的既有 Netlify 预览流程。
- 不合并 main，不覆盖阿里服务器上的生产网站。
- 不修改 supabaseClient.js、登录/注册页、支付、订单、会员权益、watch.html、视频 API 或数据库结构。
- 动态、文章、产品矩阵、科研销售与过期会议退出首页，但原页面及历史数据不删除。其他业务放页脚次级入口。

## 实现

1. 四项主导航：首页、视频课程、培训报名、我的学习。首页访客也可找到我的学习，实际登录要求仍由目的页执行；其他页面保持旧导航。
2. 培训卡展示现有三项专科入口，另保留肾小球病与透析通路链接。价格、班期、招生状态不在首页重复硬编码。
3. 精选视频读取既有静态目录及 learning_videos 的公开元数据；默认跨专科展示三条，搜索/专科筛选最多六条，并始终保留完整视频库入口。
4. 首页只读取 id/title/speaker/category/source/is_paid/membership_accessible/created_at/enabled/deleted_at；不读取播放 URL、Aliyun 凭据、订单或权限 RPC。观看沿用 watch.html；静态条目保留原 id+bvid 形式。
5. 免费/会员/付费标签只描述目录类别，不推断已购权限。不将所有非会员付费视频错误标为“培训专属”；非 GlomCon 内容也参与展示和搜索。
6. 目录超时或部分失败明确说明，不显示伪完整目录或演示课程。专家与机构各类别独立失败，专家总数不完整时显示“—”。
7. 专家卡默认收起长简介，以真实图片、姓名、已有机构信息为主。展开按钮使用原生 button、aria-expanded/controls；无自动轮播，左右按钮及原生横向轻扫保留。
8. 手机单列内容、可换行筛选、44px 级操作目标、16px 搜索输入、三项底部快捷栏、刘海/底部安全区留白、可滚动菜单与焦点约束；减少动态效果偏好受尊重。
9. 首页专用样式不改变其他页面主题；联系邮箱复制、原生 details 帮助与无脚本目录入口均可回退。

## 图像素材与性能

使用内置 imagegen 创建三张无字主题装饰背景：蓝紫微观纹理、蓝色流体、青色肾形。不是病理诊断图，不生成专家照片。
最终网页资源使用 WebP：pathology-v1.webp 65,320 bytes；critical-v1.webp 30,574 bytes；transplant-v1.webp 33,642 bytes。三张合计 129,536 bytes（约 126.5 KiB）；PNG 源图另行保留，不在网页中请求。
提示词要点：深暗左侧留白、右侧精细医学主题装饰、16:9、无字/无logo/无人像。
