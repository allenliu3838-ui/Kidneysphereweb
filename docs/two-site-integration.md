# 学习门户与医生工作台联动

本次接续主站 PR #186 / `codex/portal-home-20260913`，保留现有视频、培训、课程权益和登录逻辑。配套医生端修改在 Doctorapp_web PR #40。提交完成和测试通过均不代表已部署到阿里云。

## 用户入口

| 入口 | 目的地址 | 行为 |
| --- | --- | --- |
| 学习门户 | `https://kidneysphere.com/` | 视频、培训与我的学习；主站内部使用相对的 `index.html` |
| 医生工作台 | `https://kidneyspheredoctorapp.cn/` | 进入医生端首页 |
| AI 助手 / AI 辅助学习 | `https://kidneyspheredoctorapp.cn/#/ai` | 进入医生端现有 AI 路由 |
| 临床计算工具 | `https://kidneyspheredoctorapp.cn/#/tools` | 进入医生端工具目录 |

共享 `app.js` 在所有采用标准页头的主站页面上加入 44px 高的站点切换入口，登录前后均可见；首页的课程入口与底部学习导航保留。手机不用打开菜单就能进入工作台。首页补充两个紧凑的 AI / 工具入口；页脚工作台链接同样在当前标签页打开。旧 `shared/ks-topbar.js` 未被主站页面引用，本次不改动它或其他产品站点。

浏览器“返回”可沿普通浏览历史回到来源页。所有跨站地址固定，不携带患者内容、令牌、账号或动态返回参数；此功能不是跨域单点登录。首次在某个域名使用时，可能需要按该站现有流程登录；课程和已购权益仍在学习门户的“我的学习”查看。没有新增购买入口或复制订单，原账号与权益接口保持原样。本次未验证真实账号跨域登录，也未验证已购课程播放。

AI 入口仅连接现有医生端功能，不代表已配置某家模型的 API 或承诺模型一定在线；可用状态及人工复核说明由医生端页面呈现。

## 发布范围与顺序

主站是静态站点，没有根目录 npm 构建步骤。生产更新应来自审阅后的确定提交，并先按当前发布流程备份。

本次主站运行文件：`app.js`、`index.html`、`portal-home.css`。先发布 CSS、共享脚本，再发布 `index.html`；文档和测试不放进网站目录。现有 `deploy/build-portal-release.py` 和 `deploy/build-portal-ecosystem-release.py` 固定了旧提交及旧文件范围，不能直接拿它们当成本次发布包。

既有记录中的主站目录是 `/var/www/kidneysphere`，医生端构建输出目录是 `/var/www/kidneysphere-doctor/dist`。发布前由运维核实当前 Nginx 指向，不能仅凭历史路径覆盖。医生端按其项目说明构建和发布。

首页已为更新的 `app.js` 与 `portal-home.css` 使用 `20260918_bridge1` 版本参数。共享脚本的其他页面仍有原版本 URL；如使用 CDN 长缓存，发布时需使 `app.js` 所有查询参数版本失效，并确认静态 JS 的浏览器缓存策略允许更新。验收使用新浏览器会话或禁用缓存，另外再检查已有会话。

建议先发布医生端并检查 `/#/ai`、`/#/tools`，再发布主站，避免用户从主站进入尚未就绪的目标页。回滚时分别恢复两站本次修改前的运行文件；不需要数据库迁移或配置修改。

## 验证

本轮本地结果：77 项首页、动效及专家轮播回归全部通过，`app.js` 语法检查与 `git diff --check` 通过。Chromium 在 320、390、768、1024、1440px 下检查：首页无横向溢出，新增的 5 个导航 / 快捷链接均为 44px 高且在当前标签页打开；390px 视频库也显示站点切换条且无横向溢出，手机菜单可打开并用 Escape 关闭，没有页面脚本异常。截图人工检查了 390px 和 1440px 的首屏。

浏览器检查屏蔽外部请求及 `/api/`，未读取真实用户数据；因为测试环境缺少中文字体，检查时仅在浏览器中加载 Noto Sans CJK 字体，不将其加入生产资源。上述结果不包含生产 API、真实登录、已购课程或跨站身份验证。

在主站仓库执行：

```bash
node --test tests/portal-home.test.mjs tests/portal-motion.test.mjs tests/portal-showcase-rotation.test.mjs
node --input-type=module --check < app.js
```

- 320px、390px、768px 和桌面宽度：站点切换条没有横向溢出，链接高度至少 44px；手机菜单和底部学习入口正常。
- 首页、视频库、我的学习均可到达工作台，医生端“学习门户”能返回主站；点击后没有新窗口。
- AI 和工具链接进入对应路由；返回按钮回到来源页。链接中不出现登录令牌或患者信息。
- 游客和真实已购测试账号分别验收原有登录、我的学习、课程权限与播放。无法访问已购内容时先核对购买账号与权益，避免重复购买。

本地无凭证、屏蔽外部请求的界面检查不能替代上述生产验收。
